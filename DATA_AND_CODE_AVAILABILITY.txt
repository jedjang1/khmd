Data and Code Availability — draft, local preparation only

KHMD0.0.5 source and the validated source archive, documentation and synthetic
examples are prepared locally for a future code repository. A separate construction-
code candidate includes both basev0_1 and connectionv0_2 and their required local
modules, input contracts and selected synthetic validation tools. It is not a claim
of independently reproduced nationwide processing from externally supplied inputs.

The proposed data deposit contains the sparse1-km grid-by-contract-quarter-by-family
observation-count panel, metric/rental-level price distributions, source-region quality
tables and linked provenance/grid manifests. It does not contain original CSV rows,
parcel boundaries, PNU, representative-point datasets or individual-observation stores.
The Windows binary ZIP is not included in this first publication candidate.

Project-authored code is MIT. MOLIT continuous cadastral geometry (NA:23), reference
2026-09-08, was used under CC BY2.0 Korea; the transaction CSV portal's unrestricted-
use indication is documented. Source licences and derived-data conditions are distinct
from the code licence. Separate database-maker-rights scope and the transaction
download screen's official-statistics guidance remain unresolved interpretations.
No new blanket licence is assigned to the aggregate data, and this text neither
announces agency approval nor declares additional permission categorically necessary.

All assets remain local; no repository, public download URL or DOI has been issued.
Complete actual repository/deposit identifiers only after an external publication
decision and deposit. Repeated occurrences, cancelled-date-displayed sales, source
observability and sparse-group limitations remain. These are descriptive observations,
not proven population totals, fully anonymous microdata or historical-position proof.

# khmd 0.0.5 — private code repository

Author and maintainer: Jinhyeok Jang <jedjang1@gmail.com> (aut, cre).

This repository contains the selected code, documentation and fabricated examples
from the validated local publication candidate. It is a private upload, not a
public release. No DOI or public data-download address has been issued.

- `code/khmd/` and `code/khmd_0.0.5.tar.gz`: validated R source and source archive.
- `construction/`: both construction v0_1 dependencies and v0_2 connections.
- `example_data/`: synthetic examples only; their SQLite files are fabricated.
- `README.txt`: package installation and query instructions.
- `construction/README.txt`, `EXTERNAL_INPUTS.txt`: construction sequence and
  separately supplied external inputs.
- `GITHUB_FILES.csv`: inventory of this upload, excluding its own self-hash.

The aggregate `data/` directory is deliberately absent. Its 10 files are reserved
for a separate data-preservation repository, not uploaded here. The inherited
`DISTRIBUTION_FILES.csv`, `FILE_INVENTORY.json` and `UPLOAD_LIST.csv` describe the
combined local candidate and retain data entries as provenance/planning records;
they do not assert that those data files are present in GitHub. Full-data examples
and whole-bundle verification require the matching separately supplied data tree.
No original CSV, parcel geometry, individual-observation store, real PNU/point
dataset, internal diagnostic log or Windows binary ZIP is included.

Project-authored code is MIT; data terms are separate. See `LICENSE.txt`,
`DATA_SOURCES.txt` and `PUBLICATION_STATUS.txt`. NA:23 attribution and the existing
two unresolved rights-interpretation questions are retained. MIT is not assigned
to all derived data. Private uploading does not resolve those questions or
authorize public disclosure. The prior local checks are historical evidence;
this upload does not rerun build/check or independent nationwide construction.

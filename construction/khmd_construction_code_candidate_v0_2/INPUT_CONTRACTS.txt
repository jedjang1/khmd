External inputs for the V2 handoffs (not included)

These are JSON configuration templates, NOT a command to start national processing.
All file paths are resolved relative to the configuration file. Every input requires role, schema, source, version, reference_time, acquisition_time_status. UNKNOWN is an explicit observation state; null is unfinished configuration. expected_sha256 is checked when supplied. If deliberately omitted for a genuinely new file, the binder streams and records its new hash as HASH_RECORDED_THIS_BINDING, not a previous verification. Scope SYNTHETIC never supplies an EXTERNAL stage. No old status or SHA is copied onto new input bytes.

- geometry_config + grid_policy: the exact producer inputs; checkpoint meta equals digest of their actual SHA pair.
- candidates: key_results and candidates SQLite; candidate_input, candidate_manifest, candidate_publication and candidate_completion are the existing supervised candidate-publication contract. Preserve actual candidate counts, occurrence weights, DBF row SHA, PNU/ordinal identity.

- demand: files(sha,family,query_json,input_rows,complete,province), weights(file_sha,key_id,quarter,row_status,n), from the selected release.
